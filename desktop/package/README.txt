Vesper for Windows (early test build)

1. The installer (vesper-desktop-windows-x64-setup.exe) installs Vesper for you alone, without admin: a Start menu
   entry, a desktop shortcut if you want one, vesper:// links (invites and rooms) opening in Vesper, and an entry in
   Settings > Apps to remove it. Or unzip the portable zip anywhere you like and run Vesper.exe.
2. Windows may say "Windows protected your PC". The app is not signed yet. Click "More info", then "Run anyway".
3. Sign in with the server address (for example https://vesper.tfaucher.com), your username and your password.
   New here? Open your invite link and pick "Open in the desktop app", or make the account in the web app.
   Passkeys are only in the web app.
4. Use headphones in calls. The desktop app has no echo cancellation yet.
5. Push to talk works while a game has focus. Pick the key in Settings. A game running as administrator may hide
   its keys from Vesper; run Vesper as administrator too if push to talk does nothing in that game.
6. You can watch other people's screen shares in a call. Sharing your own screen is only in the web app for now.

Updates: Vesper checks GitHub for a new version every few hours and shows "Update and restart" when there is one. It
installs nothing until you click it, and it checks the download's SHA-256 first. It keeps the old Vesper.exe beside the
new one as Vesper.exe.old. Settings > Desktop app turns the check off.

The noise filter downloads about 8 MB the first time you join a call.
This is a test build. Tell Toby what breaks.
