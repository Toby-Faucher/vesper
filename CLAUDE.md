# vesper: rules for agents

Rust workspace (`crates/`) plus a Svelte 5 and Vite web app (`web/`). One server binary, `vesper-server`. Start with `README.md`, then
`docs/architecture.md` (how the parts fit), `docs/dev.md` (run, test, build the denoiser) and `docs/env.md` (every variable).

- **Toolchain is pinned** in `rust-toolchain.toml` (1.99.1). Do not change it inside an unrelated commit.
- **Never run a blanket `cargo update`.** `tract-core` is pinned `=0.21.4` (other versions trip a debug assertion on the DeepFilterNet3 model; see the
  `[profile.dev.package.tract-core]` note in `Cargo.toml`). Update one crate: `cargo update -p <crate> --precise <ver>`, then run `scripts/check.sh`.
- **The `wasm-bindgen` crate in `Cargo.lock` and the `wasm-bindgen` CLI must be the same version.** `scripts/build-dsp.sh` checks it and prints the
  install command. Never bump one without the other.
- **Run `scripts/build-dsp.sh` before any web build or run.** It writes `web/public/dsp/` (wasm plus model). Without it the app falls back to
  browser suppression. Never commit the model or `web/public/dsp/`.
- **The join key is `VESPER_DEV_KEY`.** It is required, and the server refuses to start without it. Never put a real key in a file, a doc, a test,
  a log line or a commit message. Docs use `pick-a-passphrase`. `Config`'s `Debug` prints `***`; keep it that way.
- **Never commit** `.env`, keys, certificates, logs, the model, `web/public/dsp/` or `target/`. `scripts/check-secrets.sh` looks for secrets in tracked files.
- **Builds on this machine go through `scripts/capped.sh`** (a memory-capped systemd user scope, no root): `scripts/capped.sh cargo build --release`.
  `scripts/check.sh` and the `just` recipes already do it. An uncapped release build of `tract` and `str0m` can run the machine out of memory.
- **Never run `sudo` directly.** Use `sudoq run --why "<reason>" -- <command>`. Exit 77 means denied: stop and ask. Exit 75 means nobody answered.
- **`scripts/check.sh` must pass before a PR.** `scripts/check.sh fast` is fmt, clippy and tests. `scripts/check.sh --help` lists the steps.
  CI runs the same steps.
- **Wire types live in `crates/vesper-protocol`.** `web/src/lib/gen/*.ts` is generated by `ts-rs`. Change the Rust type, run
  `cargo test -p vesper-protocol`, commit the regenerated files. Do not edit `gen/` by hand.
- **The server's `user_id` is 32 lowercase hex characters** (`rooms.rs`) because it is also the MSID stream id of a forwarded track. The client keys
  remote streams on it. Do not change its format without changing `web/src/lib/signaling.ts` and `peers.ts`.
- **Capture order is fixed:** mic, browser echo cancellation, DeepFilterNet, gain, Opus. The fallback is `deepfilter`, then `browser`, then `off`.
- **`unsafe` is forbidden** in every crate. Do not add an exception.
- **Wording.** README, docs and web strings use short, plain sentences. No em dashes, no stock AI phrases. `scripts/check-wording.sh` fails on the
  list in `scripts/wording-banned.txt`. Reword a line; do not add an allowlist.
- **Say what was verified.** In docs keep "verified", "not verified" and "unknown" apart, and say how. Docker, a real browser, Dockge, Caddy and the
  router forward are not verified on the dev machine.
- **Docs live once.** Env vars: `docs/env.md`. Run-locally steps: `docs/dev.md`. Other docs link to them. Change a variable, route or message in
  the same commit as its doc.
- **Not an agent's decision:** the LICENSE, making the repo public, a changelog, and anything marked **[Toby]** in the specs.
